# HIV-1 Protease Docking (PDB: 1HSG)

This folder documents the HIV-1 protease docking workflow explored with AutoDock Vina, Meeko, and PyMOL. The ligand used in the recorded workflow was labeled `MK-1`.

## Workflow areas
- Inspect the original PDB structure and identify the ligand/residue records.
- Prepare receptor and ligand files with documented settings.
- Inspect the binding pocket and define the Vina search box.
- Run docking and record the actual score and configuration.

## Add your original artifacts
Add the retained preparation scripts, Vina configuration, small log excerpts, and output poses if available. Include the exact search-box parameters and docking score from your own output. No docking score is asserted in this starter documentation.
